# JX3 Unbounded Daily Planner

[简体中文](../index.md)

A Windows desktop utility built on ok-script. Its first built-in task, **Daily Checklist**, organizes daily activities, estimates time, and lets the user record completion manually. The current version does not operate the game.

## Configured Target

- Client process: `JX3ClientX3DX64.exe`
- Resolution: minimum `1280×720`, aspect ratio `16:9`
- Repository and update source: [F1216695953/jx3](https://github.com/F1216695953/jx3)
- Window class is unknown, so default matching is retained; the template icon remains in use
