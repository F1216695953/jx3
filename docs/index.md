# 剑网3无界日常助手

[English](en/index.md)

这是一个基于 ok-script 的 Windows 桌面工具。目前首个内置任务是“每日清单”：整理日常事项、估算用时，并由用户手动记录完成情况。当前版本不自动操作游戏。

## 已配置目标

- 客户端进程：`JX3ClientX3DX64.exe`
- 分辨率：最低 `1280×720`，宽高比 `16:9`
- 仓库和更新源：[F1216695953/jx3](https://github.com/F1216695953/jx3)
- 窗口类名未知，保留默认匹配；图标继续使用模板图标
